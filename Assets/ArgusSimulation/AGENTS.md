# AGENTS.md: Assets/ArgusSimulation

The simulator's C# source: a pure-C# Core that also builds without Unity, plus the Unity adapters,
editor tools and tests. Class placement is decided by
[docs/code-organization.md](../../docs/code-organization.md); check it before adding a file.

| Folder | Assembly | May reference |
|---|---|---|
| `Core/` | `Argus.Simulation.Core` (`noEngineReferences`) | nothing: no Unity, Cesium, gRPC or Protobuf |
| `Unity/` | `Argus.Simulation.Unity` | Core, Cesium, Unity.Mathematics, Input System, the stream plugin |
| `Editor/` | `Argus.Simulation.Editor` (Editor only) | Core, Unity, Cesium |
| `Tests/EditMode/` | `Argus.Simulation.Tests.EditMode` | Core only |
| `Tests/PlayMode/` | `Argus.Simulation.Tests.PlayMode` | Core, Unity, Cesium, test runner |

## Build and test

Core and the EditMode tests build without Unity, from the repository root:

```bash
dotnet test headless/Tests/Argus.Simulation.Tests.EditMode.Headless.csproj
```

Everything under `Unity/`, `Editor/` and `Tests/PlayMode/` needs Unity 6000.6.0f1; CI does not
compile it. Before opening the project, build the stream plugin once (and after any contract
change): `dotnet build Argus.Contracts/Unity/Argus.Stream.Contracts.csproj`. Run PlayMode tests
with a GPU (never `-nographics`), from the Test Runner window or:

```bash
"$UNITY_EDITOR" -batchmode -projectPath . -runTests -testPlatform PlayMode -testResults playmode.xml
```

If you change Unity code and cannot run Unity, say so in the PR.

## Core rules

- **Headless (D1).** Core compiles with plain `dotnet` (C# 9, netstandard2.1). No `UnityEngine`
  or Cesium; use the double-precision vector, quaternion and matrix types in `Core/Math/`.
- **Contracts.** Stable DTOs go in `Core/Contracts/`; sensor and camera DTOs stay with their owners
  in `Core/Sensors/` and `Core/Imaging/`. A change to a type mirrored in `Argus.Contracts/` lands
  with the `.proto` change in the same PR.
- **Basilisk mapping is internal (D8).** Types in `Core/Basilisk/` are `internal`, visible only to
  the host and EditMode tests (`Core/AssemblyInfo.cs`). Frame conversion from J2000 happens once,
  in `BasiliskStateMapper`.
- **Devices (D11).** A new sensor or actuator is a kind registered in `Core/Contracts/DeviceKinds.cs`,
  not a new field on a contract. Basilisk-modelled sensors only publish mapped measurements
  through `BackendSensorModel<T>` and never compute, hold or repeat a value (D10). See
  [docs/device-model.md](../../docs/device-model.md).
- **The gateway never exposes truth (D7).** Controllers get observations through each kind's
  controller projection; only the recorder sees `SimulationState`.
- **Recording (D6).** `Core/Recording/RunRecorder` is the only export route; dataset v1 is
  additive only ([Core/Recording/README.md](Core/Recording/README.md)).
- One public top-level class per file; tests mirror the production folder they cover.

## Unity rules

- **Unity follows the host (D2, UNITY-6).** `SimulationRunner` only follows the host's state
  stream. `HostLauncher` may start the host process on Play, but Unity never steps, paces or
  runs a simulation of its own.
- **Unity renders cameras; it doesn't model them (D5).** Exposure time, pose and calibration come
  from Core camera kinds. Unity implements `IImageRenderer` and converts from OpenCV camera axes
  (+x right, +y down, +z out of the lens) to its own. See
  [Unity/Cameras/README.md](Unity/Cameras/README.md).
- **gRPC only at the stream endpoint.** Only `Unity/Runtime/StateStreamClient` and
  `StateStreamMapper` touch the generated `argus.stream.v1` types; never UI classes.
- **Scenes.** `Scenes/Foundation.unity` is generated by **Argus Simulation > Create Foundation
  Scene** (`Editor/Scene/FoundationSceneBuilder.cs`). Regenerating overwrites the tracked scene, so
  put scene changes in the builder, regenerate, and commit both.
- **`.meta` files.** Every file and folder here has one. Move or rename a file together with its
  `.meta`; never delete or regenerate one, or scene references break. A new file needs a `.meta`
  with a new random GUID (Unity writes it when the project opens; commit it).
- Never commit `Plugins/` (the generated stream plugin) or the Cesium token in `.env`.
